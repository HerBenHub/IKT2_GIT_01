# GIT practice tasks
## Technologies

- GIT
- HTML
- CSS
- JavaScript

**HTML:** Egy leíró nyelv, a rövidítés a "Hypertext Markup Language"-re utal. Tag-ekből épül fel, mint például ```<body></body>```
**GIT:** Ez a technológia lehetővé teszi a verziókezelést különböző szoftverfejlesztések során. A GIT-et Linus Torvalds fejlesztette ki a Linux kernel fejlesztéséhez. Nyílt forráskódú. 
Sokszot kiadott parancsai közé tartozik a ```git clone https://github.com/HerBenHub/IKT2_GIT_01.git```, amikor egy repo-t ún. klónozunk a saját gépünkre.
**CSS:** A HTML oldalon található stílusok formázására a legelterjetebb megoldás a CSS, ami a "Cascading Style Sheet" rövidítést hordozza. Öröklődésen alapul és egyszerű a használata. 
A ```<body>``` tag-et az alábbiak szerint formázhatjuk hivatkozás után: ```body {margin: 0px }```
**Javascript:** Egy leírónyelv, mely főkent az oldalak interaktivitásáért felelős. Gyengén típusos. Fejlesztése során az Ecmascript-et veszik alapul, melynek jelenlegi verziója az ES6, 2015-től. 
Szintaktikája egy egyszerű üzenethez a konzola: ```console.log("Szia Attila!");```
